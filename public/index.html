Step-by-Step Configuration Guides for Top Bitcoin Wallets

Select your Bitcoin wallet application below to follow verified, exact setup instructions.

STEP 1 Creation

New Keystore

Open Sparrow -> Select File -> New Wallet. Choose New or Imported Software Wallet.

STEP 2 Credentials

Enter BIP-39 Seed

Select Mnemonic (12 words) and paste the seed phrase. Leave Passphrase blank unless configured.

STEP 3 Script Type

Select BIP-84 / BIP-86

Set Script Type to Native SegWit (P2WPKH) for m/84'/0'/0'/0 or Taproot for m/86'/0'/0'/0.

STEP 4 Verification

Verify Parity

Click Receive in Sparrow and confirm your first receiving address matches bc1qtaqn....

STEP 1 Wallet Type

Standard Wallet

Open Electrum -> File -> New/Restore -> Name your wallet -> Select Standard wallet.

STEP 2 Seed Option

BIP39 Checkbox

Choose I already have a seed -> Click Options -> Check BIP39 seed.

STEP 3 Derivation

native segwit (p2wpkh)

Select native segwit (p2wpkh). Derivation path defaults to m/84'/0'/0'.

STEP 4 Alternative

Single WIF Import

Alternatively, choose Import Bitcoin addresses or private keys and paste your WIF Compressed Key directly.

STEP 1 Import Phrase

Secret Recovery Phrase

Install UniSat or Xverse from Chrome Web Store. Select "I already have a wallet" and paste your 12-word recovery phrase.

STEP 2 Select Address Standard

Taproot / Native SegWit

Choose Taproot (P2TR) to manage Ordinals, BRC-20, and Runes, or Native SegWit (P2WPKH) for normal Bitcoin.

STEP 3 Network Mode

Mainnet / Testnet

Go to UniSat / Xverse Settings -> Network -> Toggle between LIVENET (Mainnet) and TESTNET as needed.

STEP 1 Add & Import

Add Wallet -> Import

In BlueWallet, tap + Add Wallet -> Tap Import wallet -> Enter your 12-word seed phrase or scan the QR code.

STEP 2 Auto-Detection

Native SegWit HD Wallet

BlueWallet will automatically detect the HD derivation path (m/84'/0'/0') and generate Bech32 bc1q... addresses.

STEP 3 Electrum Node

Custom Electrum Node

In BlueWallet Settings -> Network -> Electrum Server -> Enter electrum.blockstream.info:50002 for private broadcast.

STEP 1 Install MetaMask Snap

MetaMask Bitcoin Snap

Navigate to the official MetaMask Snaps Directory and enable the Bitcoin Snap or ShapeShift Multichain Snap.

STEP 2 Authorize Permissions

Derive Bitcoin Accounts

Approve the Snap permission to derive Bitcoin Secp256k1 keys from your MetaMask seed phrase under BIP-84.

STEP 3 Dual-Chain Asset View

Manage BTC + EVM Assets

View your native Bitcoin BTC balance alongside your EVM tokens (ETH, CCT, WBTC) in one unified interface.

STEP 1 Config File

Install bitcoin.conf

Click "bitcoin.conf (Core)" above to download the pre-configured daemon file. Save to ~/.bitcoin/bitcoin.conf.

STEP 2 Start Daemon

Launch bitcoind

Start the daemon: bitcoind -daemon. It will index transactions and enable the JSON-RPC interface on port 8332.

STEP 3 CLI Import

Import WIF Key

Run: bitcoin-cli importprivkey "<WIF_KEY>" "CommandCenter" false to track all anchored ledger transactions.
